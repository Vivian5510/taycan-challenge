# 测试组织

- 四个候选所有编译在性能开始前完成；前置12格结束后才逐格筛选，没有复用上一轮成绩。
- 筛选保持同一百万唯一Key、32线程、4GiB和32/256B，只有两项明确I/O开关不同。
- 候选不改变持久化同步或返回语义，不恢复group commit；只在新实验分支修改。
- 操作同步写线程只处理小块热日志pwrite；回调保持在TryComplete，冷数据/磁盘索引/大写入/读取保留AIO。
- 热日志普通文件缓存与RocksDB默认WAL缓存方向一致，但不声称等同于全部RocksDB缓存配置。
- 筛选单轮只用于选候选；最终收益以冻结参数两轮对照为准。成功库保留日志/指标/文件清单后清理，失败不覆盖。
