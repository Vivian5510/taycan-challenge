# 实验分支与依赖

`main` 保留引入原版 Helio 前的源码基线。每项架构实验在 `experiment/*` 分支开发，
提交记录说明测试结果和未完成项，不把多个失败候选反复叠在同一基线上。

`analysis/`、`build/` 和数据库不进入 Git；报告、运行脚本和必要小型清单可显式加入。
成功实验的数据库及时清理；保留诊断所需失败样本。运行时至少保留 20 GiB 空间，
单个开发数据库上限 2 GiB，超限应停止并保留失败记录。

优先直接链接固定提交的上游源码，不重新实现其调度、队列、通知等逻辑。
确需修改时，记录原源码、具体不兼容、最小修改和验证。源码依赖以
`dependencies.json` 及实验分支的子模块提交锁定；不以预编译产物作为提交依赖。
